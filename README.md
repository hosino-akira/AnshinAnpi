# AnshinAnpi — 安心安否確認システム

顔確認と、事前登録した連絡先への安否確認メール送信を行うための画面デザイン・ソースコードです。

## プロジェクト構成

| ディレクトリ | 内容 |
| --- | --- |
| [anshin-anpi-admin-source](anshin-anpi-admin-source/README.md) | 利用者画面とPC向け管理者画面（`/admin`）を含む実装 |
| [安心安否確認システム_画面デザイン_コメント付きソースコード](安心安否確認システム_画面デザイン_コメント付きソースコード/README.md) | Androidタッチ端末向け利用者画面の、コメント付きソースコード |

各ディレクトリは独立したアプリです。起動方法、画面一覧、API接続方法は、それぞれのREADMEと`docs/`を参照してください。

## 管理者画面を含むアプリの起動

Node.js 22.13.0以上が必要です。

```bash
cd anshin-anpi-admin-source
npm ci
npm run dev
```

開発サーバーが表示するURLで利用者画面を開き、`/admin`で管理者画面を確認できます。

現在、顔特徴の登録・顔照合・メール送信・データ保存は画面確認用の疑似処理です。本番利用には、認証・API・データベース・メール配信サービスとの接続が必要です。

依存パッケージ、ビルド出力、ローカルキャッシュ、環境変数ファイルはGitの管理対象から除外しています。
