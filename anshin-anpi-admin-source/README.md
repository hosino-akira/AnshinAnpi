# 安心安否確認システム — 利用者画面・管理者画面デザイン

`/admin` は単一管理者のメールアドレスとパスワードによる認証で実APIへ接続します。登録者・送信先、メール文面、同意文面の履歴、管理情報は共有PostgreSQLから取得します。初期設定・接続先・運用方法は [管理端API](../backend/docs/ADMIN_API.md) を参照してください。旧デモ認証とサンプル登録者のリセット機能は削除しています。

高齢者を含む利用者が、顔確認を行い、事前登録した最大2名へ安否確認メールを送るための画面デザイン実装です。利用者画面はAndroid搭載の13.3インチ・タッチ液晶、管理者画面はPCブラウザを想定しています。

このリポジトリは、プログラマーが自由に画面・文言・色・遷移・接続APIを変更できるソース一式です。独自実装部分には日本語コメントを付けています。

> 現在、カメラ映像の取得は実動しますが、顔特徴の登録・顔照合・メール送信・データ保存は画面確認用の疑似処理です。本番利用には、顔認証サービス、登録情報DB、メール配信サービスとの接続が必要です。

## 対象環境

- OS: Android
- 画面: 13.3インチ、タッチ操作、横向き推奨
- 基準解像度: 1920 × 1080 px
- 最小タッチ領域: 62 pxを基準
- ブラウザ: Chromium系のキオスク表示を想定
- 管理画面: PCブラウザ、`/admin` で表示
- Node.js: 22.13.0以上

## 管理者画面

PCブラウザで `/admin` を開くと、次の管理UIを確認できます。

- 管理者ログイン：メールアドレスとパスワードを検証（共有バックエンドで検証）
- 管理状況：登録者数、メール送信先数、メール送信エラーの宛先・理由、直近の変更を表示
- 登録者管理：汎用アイコン、氏名、利用状態、顔登録状態、最大2件の送信先を変更
- 削除確認：登録者またはメール送信先の削除前に影響範囲を表示
- メール送信先管理：登録者ごとに最大2件の氏名とメールアドレスを管理
- 送信メール編集：家族へ配信するメールタイトルと本文を編集し、差し込み後の内容をライブプレビュー
- 個人情報取扱文面：本文、版番号、適用開始日を自由編集し、表示内容をプレビュー
- 管理者情報：名前、メールアドレス、パスワード、最終ログイン時刻、ログイン元IPアドレスを表示・変更

管理画面はサーバー認証、共有PostgreSQL、監査ログに接続済みです。登録者の原写真は保存・表示しません。停止後の復帰は本人立会いで顔を再登録し、利用者向け個人情報文面を版番号と適用日で管理します。公開サイトへの反映にはHTTPSバックエンドと接続先の設定が必要です。

## 起動方法

```bash
# 依存パッケージをインストール
npm run install:ci

# 開発サーバーを起動
npm run dev

# 静的検査
npm run lint

# 本番ビルド
npm run build
```

開発サーバー起動後、表示されたローカルURLをAndroid端末またはPCのブラウザで開いてください。カメラ画面ではブラウザのカメラ許可が必要です。本番ではHTTPS配信が必要です。

## よく変更する場所

### 色・文字・ボタンサイズ

`app/globals.css` 冒頭の `:root` にあるCSS変数を変更します。

```css
:root {
  --navy: #123f5f;
  --teal: #0b8179;
  --orange: #f08a24;
  --ink: #183247;
}
```

### タイムアウト・完了時間・画面確認用データ

`app/page.tsx` 冒頭の「導入先で変更しやすい設定値」を変更します。

```ts
const INACTIVITY_WARNING_MS = 60_000;
const TIMEOUT_GRACE_SECONDS = 30;
const COMPLETION_SECONDS = 10;
const MOCK_USER_NAME = "山田 太郎";
```

### 画面遷移

`app/page.tsx` の `renderScreen()` に `SCR-00`〜`SCR-14` の表示と遷移先があります。ボタンの `setScreen("SCR-xx")` が次画面を示します。画面追加時は `ScreenId`、進捗配列、`renderScreen()` の3か所を更新してください。

### 顔認証・メール送信

`runProcessing()` は画面確認用の待機処理です。本番では `docs/API_INTEGRATION.md` を参照してAPI呼び出しへ置き換えてください。

## 実装済みの安全対策

- 氏名・メールアドレスはURLやブラウザ履歴へ載せず、画面メモリ内で管理
- 中止・完了・タイムアウト時に入力情報を消去
- カメラ画面を離れた時点でMediaStreamを停止
- メールアドレスを確認画面でマスク表示
- メールアドレス形式、氏名文字数、宛先重複を検証
- 処理中の多重タップを抑止
- 無操作60秒＋警告30秒で自動終了
- 完了画面は10秒後にホームへ復帰

## 本番導入時に必須の追加対応

- 顔認証APIの生体判定、品質判定、誤認識対策
- 顔特徴データ、氏名、連絡先の暗号化保存
- 同意文面の法務確認、同意日時・文面版数の記録
- メール送信APIの冪等キー、再送、部分失敗表示
- サーバー側入力検証、認証、監査ログ、アクセス制御
- 通信障害・カメラ障害・該当者なし・複数候補のエラー画面
- Androidキオスクモード、画面回転固定、端末再起動後の自動起動
- 実機での文字サイズ、視認性、音声案内、アクセシビリティ検証

## 注意

`.openai/hosting.json` は現在のホスティング先を識別する情報を含みます。別環境へ新規展開する場合は、利用するホスティング基盤に合わせて設定を作り直してください。
